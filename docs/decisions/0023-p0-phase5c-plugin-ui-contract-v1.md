# ADR-0023：Phase 5-C 插件快照 UI 合同 v1

- 状态：已接受（2026-09-05 开发者确认全部三个确认点：停靠侧边栏视图、执行+进度+摘要卡三段式、设置页保持文本字段+校验反馈）
- 日期：2026-09-05
- 草案阶段：Phase 5-C
- 决策者：开发者
- 相关文档：ADR-0021（Phase 5 接线合同）、ADR-0022（Phase 6-0 范围裁决）、执行计划 §16、`docs/test-plans/phase5b-plugin-report.md`、`docs/test-plans/phase6a-gui-report.md`

## 1. 背景与边界

Phase 5-B/6-A 已交付"极薄"快照入口：命令面板命令 + 设置页 + 状态栏 + Notice 弹条。开发者裁决现在启动插件富前端界面（Phase 5-C）。本合同只加**表现层**：所有状态迁移仍走 `p0-snapshot.ts` 既有执行器与 `PluginSnapshotProgress` 端口事件；不修改 core、不修改 adapters、不新增任何加密/Manifest/恢复实现；ADR-0021 §2 全部禁令继续有效（无 restore 命令/UI、无默认路径、源 Vault 零写入、设置运行期锁定、runtime-limits 三方绑定、bundle 禁止 restore 表面扫描）。

## 2. 冻结规则

1. **界面载体**：Obsidian 可停靠视图（`ItemView`，视图类型 `ekd-p0-snapshot-view`）+ ribbon 图标入口；命令面板命令保留（打开视图并触发快照）。
2. **视图内容**（三段式，全部只读呈现既有数据）：
   - **执行区**：Create snapshot 按钮（运行期禁用，替代当前"仅命令面板"的触发方式）；
   - **进度区**：实时显示端口派生进度——扫描文件数、加密序号/总数、累计明文字节、持有性状态（复用 `PluginSnapshotProgress`，UI 回调异常隔离语义不变）；
   - **结果区**：最近一次运行的摘要卡（文件数、明文/密文字节、可见性摘要 + `plugin-summary-not-formal-acc-32-or-33` 免责标注、报告路径）；失败时显示错误信息与设置页指引。
3. **进度语义不变**：进度仍由端口拦截派生（`VaultSource` 计数、logSink 行拦截、RecoveryFileTarget 回读完成），core 零改动；UI 只订阅既有回调。
4. **设置页形态**：保持纯文本字段 + 即时校验反馈（不新增路径选择器）；校验失败原因直接显示在字段下。
5. **不加入历史报告列表**：结果区只呈现最近一次运行；报告文件本身仍是唯一持久记录（历史列表涉及批量读取与聚合，留待后续合同）。
6. **报告查看**：结果区提供"打开报告"动作 = 用 Obsidian 默认 JSON 查看器打开报告文件路径；不新增自定义渲染器。
7. **验证方式**：视图状态机与进度映射为可测纯逻辑（vitest）；`test:all` 全绿；bundle restore-surface 扫描保持通过；**真实 Obsidian GUI 复验**——复用 Phase 6-A 流程在 `artifacts/gui-test-vault/` 重跑一次快照并截图记录面板状态。
8. **机器状态**：接受后新增 wire token `PHASE_5_C_PLUGIN_UI_CONTRACT_ACCEPTED`；无错误码、无 DP/ACC 状态变化。

## 3. 确认点裁决记录（2026-09-05，开发者确认）

1. **界面形态**：采纳——可停靠侧边栏视图 + ribbon 图标，命令面板保留（打开视图并触发快照）。
2. **功能范围**：采纳——执行区 + 实时进度区 + 最近结果摘要卡三段式；不加历史报告列表。
3. **设置页**：采纳——保持纯文本字段 + 即时校验反馈，不加路径建议器。

## 4. 后果

- 实现切片（授权后）以 feat + docs 对提交纳管；不升级任何 ACC、不改 DP。
- 若开发者选择扩展历史报告列表，需先冻结报告目录聚合规则，另行出合同。
