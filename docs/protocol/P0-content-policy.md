# P0 内容策略与路径规则

> 文档版本：v0.2
> 当前状态：允许列表、失败关闭和 Windows 路径合同已冻结；Phase 2 Node 只读扫描实现与 review tests 已完成，正式 ACC evidence 未生成
> 日期：2026-08-27
> 权威来源：README §7、执行计划 §5

## 1. 职责

冻结 P0 的文件允许列表、未知文件行为和重解析点拒绝规则。本文件是扫描器、Manifest 生成和恢复验证的内容策略权威。

## 2. 两层文件模型

共享核心把普通文件处理为：

```text
relative_path + byte_stream + encrypted_metadata
```

加密和快照恢复不依赖文件语义。产品层使用版本化允许列表控制正式支持范围。扩展允许列表不应要求修改底层加密对象格式。

## 3. 默认允许列表（Content Policy v1）

| 扩展名 | 类别 | P0 处理方式 |
|---|---|---|
| .md | Markdown 文本 | 整文件快照、加密、恢复和字节级验证 |
| .canvas | Canvas | 整文件快照、加密、恢复和字节级验证，不解析节点语义 |
| .pdf | 二进制附件 | 整文件快照、加密、恢复和字节级验证 |
| .png .jpg .jpeg .gif .webp | 图片 | 整文件快照、加密、恢复和字节级验证 |
| .c .h .cpp .hpp .py | 代码文件 | 整文件往返，字节级验证 |

其他代码类型必须通过版本化内容策略显式加入，不能依赖"主流语言"等模糊分类自动扩大支持范围。

P0 不定义同步、冲突占位、三方合并、整文件协调或冲突 UI。上述能力属于 P1-alpha；内容策略不得通过措辞把它们提前带入 P0。

## 4. Obsidian 配置目录

P0 默认排除 .obsidian 目录及其全部内容。该目录包含插件、主题和设备专属配置，P0/P1 默认不处理。排除规则在扫描器中硬编码，不通过允许列表遗漏。

## 5. 未知文件行为（失败关闭）

当扫描发现不在允许列表内的普通文件时，必须执行以下步骤，不能静默跳过：

1. 收集该文件的相对路径和原因（扩展名未在允许列表中）；
2. 在本地报告中展示所有未知文件清单；
3. 返回 UnsupportedFilesFound 错误；
4. 不把快照标记为完成；
5. 不上传该文件；
6. 不在 Manifest 中为该文件创建条目。

## 6. 重解析点：Symlink、Junction 和其他重解析点

P0 统一失败关闭，对 Symlink、Junction 和其他重解析点：

- 不跟随；
- 不读取目标内容；
- 不上传；
- 不恢复；
- 在本地报告中显式报告路径；
- 阻止快照正式完成。

不支持任何通过重解析点逃出 Vault 根目录的路径。

## 7. 路径规则

### 7.1 根目录约束

- 路径必须始终保持在指定 Vault 根目录内；
- 扫描器不跟随逃出根目录的重解析点；
- 恢复器不允许写出目标根目录外。

### 7.2 P0 正式往返限定

- P0 正式往返验收限定为源 Vault 与目标目录均位于 Windows NTFS 默认行为下；
- 代表性 fixture 包含中文路径；
- 当前代表性 fixture 不要求空格或 Emoji，但 edge-case fixture 可以测试它们；
- 大小写碰撞通过合成 Manifest 或恶意输入测试，不要求在默认 Windows 目录中实际创建两个冲突文件；
- Windows 与 Android 的跨文件系统路径语义属于 P1-alpha 裁决。

### 7.3 相对路径保持

- 系统保证受支持文件的原始 Vault 相对路径不被同步系统破坏；
- 非空目标恢复目录必须被拒绝；
- 扫描中变化的文件不得进入伪一致快照。

## 8. 加密对象格式的内容策略独立性

内容策略版本是 Manifest 中的字段。发现未支持的普通文件时报告 UnsupportedFilesFound，不要求修改底层加密对象格式。扩展允许列表只更新策略版本和扩展名集合，不改密文对象格式的字节布局。
