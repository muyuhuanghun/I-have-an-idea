# P0 验收矩阵

> 文档版本：v0.1
> 状态：阶段 0 工作单元 11-12
> 日期：2026-08-27
> 权威来源：执行计划 §19、§11.3

## 1. 职责

定义 P0-R1 关闭的验收矩阵 schema 和全部验收要求。每个安全要求至少对应一个负面测试。P0-R1 必须区分已通过、失败、未测试、已知限制和移出范围。

## 2. 验收矩阵 Schema

每条验收要求包含以下字段：

| 字段 | 说明 |
|---|---|
| ID | 唯一标识，如 ACC-01 |
| 要求 | 一句话描述验收内容 |
| 来源 | 引用 README/执行计划/安全不变式/ADR 的条款 |
| 测试类型 | 正面（happy path）或负面（fault injection） |
| 测试方法 | 具体测试步骤或脚本 |
| 证据路径 | 测试报告文件路径 |
| 状态 | passed/failed/untested/known-limitation/out-of-scope |
| 备注 | 已知限制或移出范围说明 |

## 4. 证据路径

测试报告存放在 artifacts/test-reports/ 下，性能报告存放在 artifacts/performance-reports/ 下，均不提交 Git。验收矩阵的最终状态以机器可读 JSON 和人类可读 Markdown 两种格式保存。

## 5. 状态定义

- passed：测试通过，证据已附；
- failed：测试失败，必须停止并记录负面证据；
- untested：尚未执行；
- known-limitation：已知不满足但在关闭报告中记录的限制（如不做大小填充）；
- out-of-scope：移出 P0 范围的能力。

## 6. 关闭条件

P0-R1 关闭报告必须区分上述五种状态。任何 failed 项不得关闭 P0-R1。known-limitation 必须在关闭报告中明确说明限制内容。
